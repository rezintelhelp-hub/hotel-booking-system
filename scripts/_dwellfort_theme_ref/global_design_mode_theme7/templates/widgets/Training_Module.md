This widget is used to build online tests/training courses. 

An online course consists of a series of questions - each on its own page - and then a final results page that contains the Training Module Results widget. 

Each question page should use this widget to build the question. 

You can create alternative versions of the question to give the user opportunity to try a given question more than once. To do this add another instance of this widget to the page and make sure it uses the same tag as the other question on the page in the 'Retest pool' tag option.

To associate a question with a test use the same tag in the 'Belongs to test group' tag choice for each question.

You can choose one or two correct answers for the question. If you use two answers, both will be required.

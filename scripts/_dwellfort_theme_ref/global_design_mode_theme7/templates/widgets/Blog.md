Your website can have as many blogs as you'd like. When you add the Blog item to your page, that page becomes the 'index page' for that instance of your blog. Make sure you only have one blog index widget on a given page.

From the Webpages area, you can add new pages using the 'Blog article' template. These will become the articles that appear in your blog, ordered by the date you set in the properties menu for your new pages.

When you add this Blog widget to a page, you need to configure it to use a certain tag or tags so it knows which pages to use as part of the blog. You do this by setting the 'Tag' option from the properties menu once it has been added to your page.

The best way to add articles to your website once you have set up the Blog widget is to use the Search option in the Website area and browse by the tag you used for the blog widget 'Tag' option. When you browse by that tag, the system knows you are working with articles for that blog instance and pages you create will autotically have that tag applied, making it very fast to add new blog articles. 

The blog has many options that can be explored, including setting up sidebar categories and sidebar tags. These systems let your visitors browse and filter your blog.

When setting up sidebar categories or tags you need to configure at least one item from the blog widget settings. Once you have done that the Categories and Tags menus will show up in the properties menu for each article.

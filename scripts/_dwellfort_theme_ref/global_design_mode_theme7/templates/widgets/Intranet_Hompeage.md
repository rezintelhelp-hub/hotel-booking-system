The Intranet Homepage widget is designed to be used to display a 'home page' for in 'internal internet' or 'intranet'. This is where you use a collection of systetms to create a space for staff or teams to collaborate. 

The widget is designed to work with the following widgets: Forum, Blog, Calendar, Users List Chat and Files widgets. You should set up these widgets on separate pages as per their own instructions and the user their tags to configure this widget. You should use this widget on an otherwise empty page.

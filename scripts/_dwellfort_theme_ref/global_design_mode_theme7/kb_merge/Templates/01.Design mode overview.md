# Creating a Design in Design Mode

Design Mode in SetSeed allows you to create and edit templates that determine the overall look and feel of your website. This includes setting up the logo, menu, header, footer, and enabling between 1 to 10 template sections. These template sections become editable on each page that uses the template, with their names used as the tab names when editing a page. If a template section isn't enabled in Design Mode, it won't show as a tab when editing the page.

## Accessing Design Mode

To access Design Mode, open the main menu by clicking the blue home icon, then select **Templates** and choose the template you want to work with. Enabling and disabling features is a great way to see the impact of different settings in the live preview, helping you decide which features and options to use.

## Working in Design Mode

After selecting a template, you'll see a sidebar menu with sections to create the design for the template.

1. **Setup**

   Start with the **Setup** section. Here, you can add custom CSS, insert code in the head or body of the HTML, and adjust other top-level options. Enable or disable these options to see their effects in the live preview, which helps you make informed decisions on which features to use.

2. **Text, H. Rules & Buttons**

   Next, configure the **Text, H. Rules & Buttons** section. Specify the default font, size, and colors for text, horizontal rules, and buttons. Colors should be entered in hex values (e.g., #FFFFFF) or other valid CSS color values. All website content uses these defaults unless a specific template section has its own custom rules, which override these defaults.

3. **Header Bars, Content Bars, and Footer Bars**

   Move on to the **Header Bars, Content Bars, and Footer Bars** section. There are 3 header bars, 3 footer bars, and 10 Content Bars. Header and Footer Bars are consistent across all pages, while Content Bars correspond to template sections, varying per page. Each section (bar) has its own styles and content.

   Header and Footer Bars contain content built based on 'modules' enabled in those areas. There are three spaces per bar (left, center, and right). Left and right areas can have one or two modules; the center supports a single module.

4. **Modules in Header and Footer Bars**

   In the **Modules in Header and Footer Bars** section, you can enable various modules:

   - **Navigation Menu**: Main website navigation, usually added to a header bar.
   - **Logo**: Displays the main logo for your website.
   - **Sitewide Content Area**: Allows CMS tools to add rich content to a header or footer bar, displayed on all pages.
   - **Social Icons**: Display social icons based on social links defined in Settings.
   - **Checkout Link**: Links to the page with the Checkout widget.
   - **Checkout Icon**: An icon linking to the page containing your Checkout widget.
   - **Languages List**: Lists different languages in use on your website, linking to the first page in each main menu used in secondary language templates.
   - **Google Translate**: Displays the Google Translate widget.
   - **Search**: Shows a search form to allow visitors to search your website.

   There are multiple options associated with each module area, but not all of them are needed at any one time. These settings apply only if certain modules are selected. For example, if you choose the Logo for the Left Module, then the Logo Image option in the same section gets used for that and that’s where you’d upload the logo image file. If the Left Module uses another module, then you can ignore options that relate to the Logo in that section. Similarly, you only need to populate the Sitewide Content Name fields if you choose ‘Sitewide Content Area’ for that module.

5. **Background Settings**

   In the background settings section, specify background colors, upload images, and select background modes (Fill, Tile, Parallax). An advanced mode, Combined Parallax, creates a 3D effect, requiring layered images. Optional settings include enabling staff to edit backgrounds per page by enabling the **Enable Backgrounds As Template Section** option and specifying a name for the template section tab to make it easy for content editing staff to understand the role of the template section. Background video can be treated similarly to background images.

6. **Banner Areas**

   Each Content Bar can have an optional Banner Area enabled, which is an additional template section above the Content Bar. Banner Areas are designed to display images at the full size of the window with optional text or buttons over the image. Multiple images can be used to create a slideshow in this area, providing a higher impact way to display content images on the page. Content editing staff can work with Banner Areas by adding images or Banner Widgets.

7. **Font and Color Settings for Content Bars**

   Each Content Bar has its own font size and color settings, which can create unique styles for the content in that bar. These settings override the default settings specified in the ‘Text, H. Rules & Buttons’ area if set to values other than ‘inherit’.

By following these steps, you can effectively use Design Mode to create and manage the design of your website templates. This ensures a professional and consistent appearance across all pages, allowing for defined roles and making it easy to maintain a consistent design regardless of content-level changes on individual pages.

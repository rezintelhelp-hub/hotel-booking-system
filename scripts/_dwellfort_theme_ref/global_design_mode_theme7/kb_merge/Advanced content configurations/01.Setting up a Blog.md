# Setting up a Blog

SetSeed includes an advanced widget that can be used to create a blog area on your website. This document explains how to set up the Blog widget initially, create articles, and manage comments.

## Understanding How the Blog Widget Works

### Inner Templates
The blog widget utilizes 'inner templates', which are special templates for creating new pages that require a specific widget on their parent page. For instance, the blog widget must be placed on the main blog index page. New blog articles are created using the special template provided by the blog widget. These articles display on their own unique pages but follow the same format prescribed by the blog widget.

### How Tags Are Used with Inner Template Widgets
Tags identify that a blog page belongs to a specific blog widget index page. This allows multiple blogs on a single website by using different tags. Tags can also be configured to display sidebar categories, enabling visitors to browse by category.

### Activity Feed
Blog articles allow visitors to add comments, which are collected in the SetSeed Activity feed. These comments can be moderated by your staff and can be set to require approval before being displayed on the website. They can be viewed under the Activity > Page Events section in the SetSeed main menu (Blue home button).

## Initial Setup

To create a blog:

1. **Decide on the main blog index page**:
   - Choose which page will serve as the main blog index page.
   - Edit that page.
2. **Insert the Blog widget**:
   - Click the **+** button to open the insert palette.
   - Find the Blog widget under Advanced & Setup.
   - Drag the Blog widget into the page.
3. **Create and assign a tag**:
   - Open the properties menu by right-clicking on the blog widget or selecting it and clicking the ellipsis button.
   - Use the ‘Quick Add Tag’ option in the Tags menu within the properties menu to create and assign a tag for the blog widget.
4. **Configure the blog**:
   - Adjust the options in the blog properties menu to configure the blog.
   - Add sidebar categories and labels to allow visitors to browse your blog. These also use tags and can be created and selected using the Quick Add Tag options.
5. **Publish the blog index page**:
   - Once the blog widget is configured, publish the blog index page. It is unlikely you will need to edit this page again. All blog workflows are managed in the Pages & Content area or the Activity feed.

## Creating New Blog Articles

To create new blog articles:

1. **Add the blog tag as a shortcut**:
   - Click ‘Pages & Content.’
   - Click ‘Page Tags Setup.’
   - Click the star icon next to the tag you created for the blog.
   - Click Done.
2. **Access the shortcut**:
   - In the Shortcuts area, click the shortcut for the blog tag. This filters your pages by that tag, showing only your blog articles.
3. **Create a new blog article**:
   - Click the **+** icon. The system will automatically show the correct ‘Blog article’ template because you are browsing pages by a tag configured for an ‘inner template’ enabled widget.
   - Drag the template into the list area to add a new article.
   - Name the article and treat it like any other page.
4. **Manage categories and labels**:
   - You will see a ‘Categories’ menu, which lists any tags selected for use as ‘Sidebar categories,’ making it easier to manage these tags.
   - The same system is used for tags in the ‘Sidebar labels’ list.

## Working with Comments

The blog widget uses the ‘Page Events’ Activity feed, which allows widgets to add repeating data items to a given page. Each blog article page allows public comments to be added in a date-ordered list.

To enable this feature:

1. **Enable comments**:
   - In the Blog widget properties, ensure the Comments option is enabled.
   - This will add a comment form to the article pages.
2. **Moderate comments**:
   - When a visitor adds a comment, it will be visible in the Activity > Page Events > (Your blog name) feed.
   - Each blog comment has a checkbox for approval. If the ‘Comments require approval’ option is enabled, only approved comments will be displayed on the website.
   - Comments can be removed by deleting them from the Activity feed.

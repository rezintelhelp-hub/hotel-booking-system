# Setting Up a Forum

The Forum widget enables the creation of a forum area on your website, where logged-in users can post and participate in discussions. This document explains how to set up the Forum widget and manage categories.

## Understanding How the Forum Widget Works

### Inner Templates

The Forum widget utilizes 'inner templates', which are special templates for creating new pages that require a specific widget on their parent page. The Forum widget must be placed on the main forum index page. New forum posts are created using the special template provided by the Forum widget. These posts display on their own unique pages but follow the same format prescribed by the Forum widget.

### How Tags Are Used with Inner Template Widgets

Tags identify that a forum page belongs to a specific forum widget index page. This allows multiple forums on a single website by using different tags. Tags can also be configured to display sidebar categories, enabling visitors to browse by category.

## Initial Setup

### To create a forum:

1. **Decide on the Main Forum Index Page:**
    - Choose which page will serve as the main forum index page.
    - Edit that page.
2. **Insert the Forum Widget:**
    - Click the + button to open the Insert Palette.
    - Find the Forum widget under Advanced & Setup.
    - Drag the Forum widget into the page.
3. **Create and Assign a Tag:**
    - Open the properties menu by right-clicking on the forum widget or selecting it and clicking the ellipses button.
    - Use the ‘Quick-add tag’ option in the Tag menu within the properties menu to create and assign a tag for the forum widget.
4. **Configure the Forum:**
    - Adjust the options in the forum properties menu to configure the forum.
    - Add sidebar categories to allow visitors to browse your forum. These also use tags and can be created and selected using the Quick-add tag options.

5. **Publish the Forum Index Page:**
    - Once the forum widget is configured, publish the forum index page.

## Configuring the Forum Widget

To configure the Forum widget, follow these steps:

1. **Open the Properties Menu:**
    - Right-click on the Forum widget or select it and click the ellipses button to open the properties menu.
2. **Configure the Options:**
    1. **Tag**: Choose or create a tag for the forum.
        - Use the ‘Quick-add tag’ option to create a new tag if necessary.
    2. **Tag for sticky topics**: Select a tag to designate sticky topics.
    3. **Sidebar categories**: Select or create tags to be used as categories in the sidebar.
    4. **New posts require approval**: Enable this option if you want new posts to be approved before they are visible.
    5. **Allow attachments**: Enable this option to allow users to attach files to their posts.

# Using the Consent Container Widget

The Consent Container widget is a powerful tool designed to ensure that certain content is only displayed to visitors who have agreed to the relevant consent roles. This is particularly useful for embedding iframes to third-party services, ensuring that these are only loaded once the user has given their consent.

## Adding the Consent Container Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Advanced & Setup** section.
   - Drag the **Consent Container** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Consent_Container"></span> to the desired location on the page.
2. **Adding Content to the Consent Container**:
   - The Consent Container widget has an editable zone called **Content**.
   - Drag or add the content you wish to display into this **Content** editable zone.

## Setting Up the Consent System

Before using the Consent Container widget, ensure that the consent system is enabled on your website.

1. **Enable Consent System**:
   - Go to **Settings**.
   - Click on **[Consent Banner](#consent-banner)**.
   - Enable the consent system and configure the roles as needed.

## Configuring the Consent Container Widget

1. **Opening the Properties Menu**:
   - To access the properties menu, right-click the widget or select the widget and click the ellipses button (**…**).

2. **Configuration Options**:
   - **Content**: This is the editable zone where you add the content that will be displayed once the visitor has given their consent.

By setting up the Consent Container widget and ensuring that the consent system is enabled, you can control the display of sensitive or third-party content based on user consent, enhancing the privacy and compliance aspects of your website.

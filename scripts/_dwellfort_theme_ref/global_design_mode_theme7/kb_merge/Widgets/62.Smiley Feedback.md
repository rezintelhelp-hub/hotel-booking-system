# Using the Smiley Feedback Widget

The Smiley Feedback widget allows you to collect ratings from visitors using a smiley pictorial interface, where users can choose between unhappy and happy faces. The collected data is available in the Activity > Page Events area, providing both individual responses and aggregate percentages of data.

## Adding the Smiley Feedback Widget

1. **Insert the Widget**
   - Open the Insert Palette by clicking the + icon.
   - Navigate to the **Advanced & Setup** section.
   - Drag the Smiley Feedback widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Smiley_Feedback"></span> to your page.

## Viewing Collected Data

1. **Access the Activity Page**
   - Click on the main menu (blue house icon).
   - Select **Activity** from the menu options.
   - Go to the **Page Events** section.
2. **View Individual Responses and Aggregated Data**
   - Each instance of the Smiley Feedback widget gets its own item in the Page Events menu.
   - Select the specific Smiley Feedback item to see the collected data.
   - You can see both individual responses and aggregate percentages for the selected widget.

Using the Smiley Feedback widget, you can easily gather and analyze user satisfaction data through a simple and engaging interface.

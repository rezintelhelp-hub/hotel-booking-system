# Using the Google Maps Marker Widget

The Google Maps Marker widget is found in the **Page Feature** section of the **Insert Palette**. This widget is designed to be used consecutively on the page to create a single map with multiple markers.

Each marker you want to display on the map requires a separate instance of the marker widget. There is no need for any additional widgets, as the map will automatically display based on the settings in the first marker widget.

Key Points:

#### Map Centering and Zoom:
- The first instance of the marker widget should have the ‘Center Coordinates’ and ‘Zoom Level’ set.
- These values will determine the initial position and zoom level of the map.

#### ‘Show List Menu’ Option:
- Controlled by the first marker widget.
- If enabled, ensure you populate the ‘List Title’ field for each marker. This title will appear in the list menu for each marker.

Make sure the first marker widget is configured correctly to control the map’s position and display settings.

To add the Google Maps Marker widget to a page:
1. Click the orange plus (+) icon to open the **Insert Palette**.
2. Select **Page Feature** from the left menu.
3. Drag the **Google Maps Marker** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Google_Maps_Marker"></span> to the desired location on your page.

## Configuring the Google Maps Marker Widget

To configure the Google Maps Marker widget, access the properties menu by right-clicking the widget or clicking the widget and then the ellipsis button.

1. **Address**
   - Enter the address for the marker location.
2. **Marker Coordinates**
   - Optionally enter coordinates for the marker instead of the address.
3. **Center Coordinates**
   - Enter coordinates to center the map. Only required on the first marker instance.
4. **Show list menu**
   - Enable this option on the first marker instance to display a list menu of all locations.
5. **List title**
   - Customize the name of the item in the list menu. Populated when 'Show list menu' is enabled.
6. **Google Map ID**
   - Only needed for the first instance of this widget per page. Optionally set up a Google Map ID to enable smooth panning between markers.
7. **Zoom level**
   - Set the zoom level. Only needed on the first marker instance.
8. **Group**
   - Enter a group name for this marker. Other markers with the same group name will have the same color icon and can be toggled together.
9. **Custom Google Maps API Key**
   - Enter a custom Google Maps API key if needed.

**Note:** You will need to have your website authorized in Google Maps by your provider for this to work. You can do this yourself by adding a custom Google Maps key to the Custom Google Maps API Key field. If the [Consent Banner](#consent-banner) is enabled, the map won't show until the visitor accepts functional cookies.

# Training Results Widget

The Training Results widget is used once per test when you create online training tests/courses. An online course consists of a series of questions, each on its own page, and then a final results page that contains this widget.

See the Multi Choice Question widget for more details on how to set up each question.

The results widget properties let you configure various settings related to the test. The widget has three editable zones:
- **Pass Content**
- **Fail Content**
- **Incomplete Content**

## Configuring the Training Results Widget

To configure the Training Results Widget, you need to open the properties menu. To open the properties menu, either right-click on the widget or click on the widget and then click the ellipses button.

1. **Test group**
   - Enter the tag that associates this result with a test group.
2. **Reset other test groups**
   - Enter the tag(s) of other test groups that should be reset when this test is reset.
3. **Display name**
   - Enter the display name for the test group.
4. **Pass threshold**
   - Set the percentage required for a pass.
5. **Redirect on reset link**
   - Choose a page that the user will be taken to when they retake the test.
6. **Redirect on reset all link**
   - Choose a page that the user will be taken to when they reset all tests (requires other test groups to be selected in 'Reset other test groups').
7. **Expiry**
   - Set the expiry period for the test results.
8. **Expiry SMS text**
   - Enter the text for the SMS notification when the test expires.
9. **Expire email**
   - Enter the text for the email notification when the test expires.

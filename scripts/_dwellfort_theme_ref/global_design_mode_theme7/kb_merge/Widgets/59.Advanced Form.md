# Using the Advanced Form Widget

The Advanced Form widget functions similarly to the standard Form widget but offers enhanced flexibility by allowing form fields to be added using the normal page-building tools. This widget is found in the 'Advanced & Setup' section of the insert palette.

## Configuring the Advanced Form Widget

To configure the Advanced Form widget, open the properties menu as usual.

1. **Email results to**
   - Enter the email address where form results should be sent.
2. **Redirect when sent**
   - Specify a URL to redirect the user to after form submission.
3. **Auto-responder**
   - Select an email template to automatically respond to the user after submission. If the form is set to 'Add to user list', enable the auto-responder on the User List instead. When creating an auto-responder email for a contact form, you can use the following placeholders:
     - `{FORM_RESPONSE}`: Displays the submitted form.
     - `{CUSTOMER_NAME}`: Inserts the customer's name.
     - `{CUSTOMER_EMAIL}`: Inserts the customer's email address.
     - Note: These placeholders differ from those used in User List auto-responder emails.
4. **Submit Button Text**
   - Customize the text displayed on the submit button.
5. **Thanks message**
   - Enter a message to display to the user after form submission.
6. **Filter rules**
   - Add any filter rules for processing form data.
7. **Omit data from email**
   - Select this option to exclude form data from the notification email.
8. **Add outline**
   - Toggle this option to add an outline around the form fields.
9. **Full width**
   - Toggle this option to make the form fields span the full width of the container.
10. **Centered**
    - Toggle this option to center-align the form.
11. **Add to user list**
    - Select a User List to add form submissions to.
12. **Redirect on verify email**
    - Specify a URL to redirect the user to after verifying their email.
13. **Login immediately**
    - Toggle this option to log the user in immediately after form submission.
14. **Defer choose password**
    - Enable this option to defer the password selection for the user.
15. **Hide SSO links**
    - Toggle this option to hide Single Sign-On (SSO) links.
16. **Include editable categories**
    - Toggle this option to include user-editable categories in the form.
17. **Force single category**
    - Enable this option to require subscribers to choose a single category from the list of editable categories.
18. **Disable ReCaptcha**
    - Toggle this option to disable ReCaptcha verification for the form.

## Setting Up the Advanced Form

1. **Add the Advanced Form widget to your page.**
2. **Enter a name for this instance of the contact form widget.**
3. **Add the Form Field widgets using the normal page-building tools.**
   - Drop form fields into the 'Form fields' editable zone once you add this widget to your page. You can use Groups to arrange your fields into layout widgets.

## Using the Advanced Form Widget

This type of form allows you to utilize advanced layout and functionality options, such as using the Form Page or Conditional Form Toggle widgets. These advanced features provide greater flexibility and control over how your forms are structured and function.

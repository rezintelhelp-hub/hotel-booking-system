# Using Breadcrumb Widgets

To add a breadcrumb trail to a page, showing users the ancestor pages of their current location, you can utilize the Breadcrumb widget.

The Breadcrumb widget includes options in its properties menu to customize its behavior:

1. **Include 'Home' link**: This option allows you to choose whether the website's homepage appears as the first item in the breadcrumb trail.
2. **Intro text**: This field allows you to customize the introductory text that appears at the beginning of the breadcrumb trail.

To display a breadcrumb trail on a specific page, follow these steps:

1. **Add the Breadcrumb Widget**:
   - Click the **+** button to open the Insert Palette.
   - Drag the Breadcrumb widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Breadcrumb"></span> to the desired location on the page.
2. **Open the Properties Menu**:
   - To open the properties menu for the widget, either:
     - Right-click on the widget, or
     - Single-click the widget and then click the ellipsis button (three dots) that appears.
3. **Adjust Settings**:
   - **Include 'Home' link**: Toggle this option to show or hide the homepage in the breadcrumb trail.
   - **Intro text**: Enter the desired introductory text to appear at the start of the breadcrumb trail.

By configuring these settings, you can effectively use the Breadcrumb widget to enhance navigation on your website.

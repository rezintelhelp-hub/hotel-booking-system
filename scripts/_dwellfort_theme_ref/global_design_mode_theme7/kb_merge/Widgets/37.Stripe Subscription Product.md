# Stripe Subscription Product Widget

The Stripe Subscription Product widget is found in the **Product** section of the Insert Palette. This widget allows you to set up a product on your site that charges an amount on a regular, repeating basis.

## Adding the Stripe Subscription Product Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Product** section.
   - Drag the **Stripe Subscription Product** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Subscription"></span> to the desired location on the page.

## Configuring the Stripe Subscription Product Widget

1. **Opening the Properties Menu**:
   - To access the properties menu, right-click the widget or select the widget and click the ellipses button (**…**).
2. **Properties**:
   - **Product name**  
     Enter the name of the product.
   - **Subscription interval**  
     Choose the interval for the subscription (e.g., Month, Year).
   - **Interval count**  
     Set the number of intervals between each charge. For example, entering '2' and choosing 'week' in 'Subscription interval' will charge every other week. Yearly intervals can only be set to 1.
   - **Start date**  
     Specify the start date for the first full subscription charge. Leave it empty to start as soon as the customer subscribes. If you enter a future date, you can choose to enable a prorated charge when the customer first signs up using the option below. Use MM-DD as the format for date entry for 'Year' intervals and DD for 'Month' intervals. 'Week' and 'Day' intervals are not supported for future start dates.
   - **Enable prorated pricing**  
     When enabled and the start date is set, the user will pay a prorated amount as soon as they subscribe to cover the period until the start date. This option is also used to control behavior when the price is changed for current subscribers when the **Everyone uses latest price** option below is enabled.
   - **Everyone uses latest price**  
     When enabled, if the price is changed, all existing subscribers will be moved to the new price.
   - **Prorated explanation text**  
     Enter the text that will explain prorated pricing to the user. This text is shown with the 'Subscribe' button to explain that the customer will be immediately charged for the prorated amount. Only shown when 'Enable prorated first charge' is enabled along with the 'Start date' being set with a monthly or yearly 'Subscription interval'.
   - **No payment method warning**  
     Enter the warning text to be shown if no payment method is available.
   - **Price**  
     Enter the charge for each interval payment. This must be in the lowest currency unit, i.e., for $9.99 you'd enter 999 in this field. Must be a whole number without currency symbol. Important: if you enable **Everyone uses latest price** above and you make a change to the price, all existing subscribers will be changed to the new price. You will need to make sure you give subscribers sufficient notice for such changes according to applicable laws and policies.
   - **Setup fee**  
     Enter an optional setup fee to be charged when a subscription is first subscribed to.
   - **Setup fee description**  
     Provide a description for the setup fee.
   - **Customer reminder email**  
     Select the email template to use for an email that will be sent 7 days before the subscription is set to renew.
   - **Customer welcome email**  
     Select the email template to use for an email that will be sent as soon as the user subscribes to a product.
   - **Customer cancel email**  
     Select the email template to use when a customer cancels their subscription.
   - **Admin notification**  
     Enter one or more email addresses (separated by commas) to be notified when new subscriptions are created or canceled.
   - **Dormant mode**  
     When enabled, no new signups will be allowed. Existing subscribers will be unaffected and will still see their subscription details and cancel options.

## Setting Up Your Website

To use the Stripe Subscription Product widgets, follow these steps:

1. **Add the Stripe Payment Method widget** to an area of your site only visible to logged-in users. This widget allows your customers to create a billing account in Stripe.
2. **Add the Stripe Webhook widget** to a public part of your site.
3. **Enter your Stripe credentials** in **Settings** > **Stripe**.

**Note**: For Stripe products to work, your Stripe account needs to be connected in **Settings** > **Stripe**.

Once these steps are completed, you can add the Stripe Subscription Product widgets to an area of your website that is only available to logged-in users to offer one or more subscription products.

For more details on setting up your Stripe Payment Method widget, refer to [Stripe Payment Method Widget](#stripe-payment-method).

For more details on setting up your Stripe Webhook widget, refer to [Stripe Webhook Widget](#stripe-webhook).

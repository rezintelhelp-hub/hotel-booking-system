# Using the Recent Pages Feed Widget

The Recent Pages Feed widget is used for displaying pages from the blog system or other widgets that use similar date-based inner template type pages. This widget provides various configuration options to customize the feed according to your needs.

## Adding a Recent Pages Feed Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Advanced & Setup** section.
   - Drag the **Recent Pages Feed** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Recent_Pages_Feed"></span> to the desired location on the page.

## Configuration Options

1. **Tag**:
   - Choose the tag for pages to include in the feed. This doesn't need to be the main index tag; it can be a single category tag or another tag used to create this feed.
2. **Number of Pages to Show**:
   - Set the number of pages to display in the feed.
3. **Show Image**:
   - Toggle the display of images with each item in the feed.
4. **Show Date**:
   - Toggle the display of dates with each item in the feed.
5. **Hide Future Dates Articles**:
   - Toggle to hide articles with future dates.
6. **Date Format**:
   - Use Smarty template language date format syntax (requires access to Design Mode).
7. **Show Summary**:
   - Toggle to display a summary with each item in the feed.
8. **Show Button**:
   - Toggle to display a button with each item in the feed.
9. **Sort by Date**:
   - Toggle to sort the feed by date.
10. **Omit First Item**:
   - Toggle to omit the first item from the feed.
11. **Grid Mode**:
   - Toggle to display items in a grid format.
12. **Image Width**:
   - Set the image width (requires access to Design Mode).
13. **Image Height**:
   - Set the image height (requires access to Design Mode).
14. **Retina Support**:
   - Toggle retina mode for images (requires access to Design Mode).
15. **Force Index Page**:
   - In some situations, the pages widget won't generate the full page address. If this happens, you can enter the first part of the page addresses here (requires access to Design Mode).
16. **Carousel**:
   - Toggle to display items in carousel mode (requires access to Design Mode).
17. **Autoscroll Speed**:
   - If in carousel mode, set the autoscroll speed in seconds. Set to 0 to disable autoscroll (requires access to Design Mode).
18. **Show Side Buttons**:
   - Toggle side buttons if carousel mode is enabled (requires access to Design Mode).
19. **Show Pagination Dots**:
   - Toggle pagination dots if carousel mode is enabled (requires access to Design Mode).

By configuring these options, you can customize the Recent Pages Feed widget to display content in a way that best suits your website's layout and design.

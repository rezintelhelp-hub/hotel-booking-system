# Using the Searchable Sub-Page Index Widget

The Searchable Sub-Page Index widget is a powerful tool ideal for allowing your visitors to quickly search a list of subpages that are also organized by category.

## Setting Up the Structure

1. **Create a New Main Menu Page**:
   - Add subpages to this main menu page. These subpages will be your main categories.
2. **Add Subpages to Each Main Category**:
   - Each main category subpage should have its own subpages.

## Adding the Searchable Sub-Page Index Widget

1. **Edit the Top-Level Page**:
   - Open the main menu page you created.
2. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the **Searchable Sub-Page Index** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Searchable_Subpage_Index"></span> to the desired location on the page.

## Adding Keywords for Search

1. **Access the Properties Menu**:
   - Navigate to **Pages & Content**.
   - Locate each sub-subpage you want to edit.
   - Right-click on the sub-subpage, or single-click the sub-subpage and then click the ellipsis button (three dots) that appears to open the properties menu.
2. **Edit Meta Keywords**:
   - In the properties menu, find and select the **Meta Keywords** option.
   - Enter a list of keywords separated by commas.
3. **Search Mechanism**:
   - The keywords added to each sub-subpage will power the search feature. When a visitor uses the search box on the page with the widget, it will match their search terms against these keywords and update the list to show only the matching pages.

### Example

For example, if you have a top-level page called "Products" with subpages for categories like "Cupboard Items," "Breads," and "Vegetables," and each of these categories has its own sub-subpages like "Sweetcorn," "Beans," etc., the Searchable Sub-Page Index widget will display these categories and their respective items. The search mechanism will highlight the relevant sub-subpages based on the keywords.

By following these steps, you can effectively use the Searchable Sub-Page Index widget to create an organized, searchable index of subpages on your website, enhancing navigation and user experience.

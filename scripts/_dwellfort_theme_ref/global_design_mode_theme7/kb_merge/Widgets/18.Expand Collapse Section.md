# Using the Expand/Collapse Section Widget

The Expand/Collapse Section widget creates a fun and interactive way to add content to a page, allowing your visitors to quickly scan headings and click them to read more about a topic.

When a visitor clicks a heading, the previously expanded section collapses, and the clicked one expands to show the content.

## Adding an Expand/Collapse Section Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Text** section.
   - Drag the Expand/Collapse Section widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Expand_Collapse_Section"></span> to the desired location on the page. Widgets should be added consecutively for each item you want to include on the page.

## Configuring the Expand/Collapse Section Widget

Each Expand/Collapse Section widget has two editable zones: **Title** and **Content**.

1. **Adding Content to Editable Zones**:
   - **Title**: Add the clickable title of the section. To add content, drag items into the **Title** editable zone, either directly from the Insert Palette or from elsewhere in the editor.
   - **Content**: Add the content that will be displayed when the section is expanded. To add content, drag items into the **Content** editable zone, either directly from the Insert Palette or from elsewhere in the editor.
2. **Open on Page Load**:
   - There is an option in the properties menu called **Open on page load**. When this is ticked, that section will be open when the visitor first lands on the page. This is normally ticked on the first item but not on subsequent ones.
   - To enable this option:
     - Right-click on the Expand/Collapse Section widget, or
     - Single-click the widget and then click the ellipsis button (three dots) that appears.
     - In the properties menu, tick the **Open on page load** option for the desired section.

By following these steps, you can effectively use the Expand/Collapse Section widget to create interactive and engaging content on your website, allowing visitors to navigate through information efficiently.

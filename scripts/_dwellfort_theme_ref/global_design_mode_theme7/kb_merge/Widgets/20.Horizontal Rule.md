# Using the Horizontal Rule Widget

The Horizontal Rule widget is a simple tool for displaying a horizontal divider between content. It helps in structuring content and ensuring that subsequent items do not sit next to previous content, such as a left- or right-aligned image.

## Adding a Horizontal Rule Widget

1. **Edit the Page**:
   - Open the page you want to edit.

2. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Text** section.
   - Drag the **Horizontal Rule** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Horizontal_Rule"></span> to the desired location on the page.

## Horizontal Rule Invisible

In addition to the standard Horizontal Rule widget, there is a version called **Horizontal Rule Invisible**. This widget allows you to prevent content from flowing next to previous items without displaying a visible line.

## Using the Horizontal Rule Invisible Widget

1. **Edit the Page**:
   - Open the page you want to edit.

2. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Text** section.
   - Drag the **Horizontal Rule Invisible** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Horizontal_Rule_Invisible"></span> to the desired location on the page.

By following these steps, you can effectively use the Horizontal Rule and Horizontal Rule Invisible widgets to structure your content and control the flow of items on your website.

# Intranet Homepage Widget

The Intranet Homepage widget is designed for use in protected areas of the website, specifically for internal staff intranet systems. It is located in the Advanced & Setup section of the Insert Palette. This widget enables the creation of a homepage featuring links and updates tailored for intranet users.

## Editable Zones

The widget includes the following editable zones:

- **Header Area**
- **Link Image 1**
- **Link Image 2**
- **Link Image 3**
- **Link Image 4**
- **Link Image 5**
- **Link Image 6**
- **Link Image 7**
- **Link Image 8**
- **Link Image 9**
- **Link Image 10**
- **Events Calendar**

## Configuring the Intranet Homepage Widget

To configure the Intranet Homepage widget, follow these steps:

1. Add the Intranet Homepage widget to your page by navigating to Insert > Widgets, then drag the widget to the desired location on the page.
2. Open the properties menu by right-clicking the widget or selecting it and clicking the ellipses (three dots) button.

### Properties Menu Options

1. **Link 1 Icon**  
   - Enter the icon for the first link.
2. **Link 2 Icon**  
   - Enter the icon for the second link.
3. **Link 3 Icon**  
   - Enter the icon for the third link.
4. **Link 4 Icon**  
   - Enter the icon for the fourth link.
5. **Link 5 Icon**  
   - Enter the icon for the fifth link.
6. **Link 6 Icon**  
   - Enter the icon for the sixth link.
7. **Link 7 Icon**  
   - Enter the icon for the seventh link.
8. **Link 8 Icon**  
   - Enter the icon for the eighth link.
9. **Link 9 Icon**  
   - Enter the icon for the ninth link.
10. **Link 10 Icon**  
    - Enter the icon for the tenth link.
11. **News Tag**  
    - Select the tag used by a blog widget to automatically display recent articles in the intranet homepage.
12. **News Index Page**  
    - Enter the page address manually if the link to the blog index page is not automatically generated correctly.
13. **Forum Tag**  
    - Select the forum primary tag to display recent posts from the intranet forum.
14. **Forum Index Page**  
    - Enter the page address manually if the link to the forum index page is not automatically generated correctly.
15. **Zoom Client ID**  
    - Enter the Zoom client ID if using Zoom integrations.

By configuring these options, you can customize the Intranet Homepage widget to meet your intranet requirements, providing easy access to news, forums, and quick links for your staff.

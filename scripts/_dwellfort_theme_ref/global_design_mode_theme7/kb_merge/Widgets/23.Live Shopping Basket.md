# Using the Live Shopping Basket Widget

The Live Shopping Basket widget enhances the user experience by allowing customers to add products to their basket and see the updates immediately, without being redirected to the checkout page. This is particularly useful on larger pages with multiple products.

## Adding a Live Shopping Basket Widget

### Step 1: Add a Column Layout with Sidebar

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Drag a **Column Layout** item that includes a sidebar to the desired location on the page.

### Step 2: Add the Live Shopping Basket Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Advanced & Setup** section.
   - Drag the **Live Shopping Basket** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Live_Shopping_Basket"></span> into the sidebar zone of the column layout item.

## Adding Products to the Main Content Zone

1. **Add Products**:
   - Add products to the main editable zone of the column layout item. Refer to [adding products](#adding-products) for detailed instructions.

2. **Add to Basket**:
   - Visitors will be able to click the 'add to basket' button on the products.
   - When they do this, they'll see their products add to the basket straight away without being redirected to the checkout page.

## Setting Up a Checkout Page

You need to set up a separate checkout page to complete the shopping experience. Refer to the [Creating a Checkout Page](#setting-up-a-checkout-page) guide for detailed instructions.

By following these steps, you can effectively use the Live Shopping Basket widget to enhance the shopping experience on your website, allowing users to add items to their basket and see the updates instantly.

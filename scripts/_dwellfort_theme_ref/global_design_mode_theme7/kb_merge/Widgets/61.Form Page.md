# Using the Form Page Widget

The Form Page widget works within an Advanced Form. Since it contains editable zones, it needs to be grouped before it can be placed in the editable zone of the Advanced Form.

The Form Page widget can group form fields into sections, allowing the user to fill out the form in chunks. To use this widget, add consecutive instances of it inside the Advanced Form editable zone (using Groups), and then add your form fields inside the Form Page editable zone.

## Setting Up the Form Page Widget

1. **Add the Form Page Widget**
   - Insert the Form Page widget into the editable zone of an Advanced Form using Groups.
   - This groups the Form Page widget so it can be added to the Advanced Form editable zone.
2. **Add Form Fields**
   - Place your form fields inside the editable zone of the Form Page widget.
   - This organizes the form fields into sections, making it easier for users to fill out the form in manageable chunks.

By using the Form Page widget, you can create a more organized and user-friendly form experience, especially for longer forms that need to be divided into sections.

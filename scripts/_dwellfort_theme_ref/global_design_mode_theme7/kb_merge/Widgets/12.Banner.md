# Using Banner Widgets

Banner widgets are used to display an image with a piece of text overlaid. These widgets are versatile and can be used either singly or in batches to create a slideshow. They work best in template sections set up to work with Banner widgets.

## Configuring Banner Widgets

### Adding a Banner Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Media & Files** section.
   - Drag the Banner widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Banner"></span> to the desired location on the page.

### Setting Text Position

Banner widgets include a **Text position** option in the properties menu that allows you to position the text in different areas of the image.

1. **Open the Properties Menu**:
   - Right-click on the Banner widget, or
   - Single-click the widget and then click the ellipsis button (three dots) that appears.
2. **Adjust Text Position**:
   - In the properties menu, set the **Text position** to one of the following options:
     - Top
     - Middle
     - Bottom

### Text Alignment

You can handle the alignment of the text within the Banner widget using the standard text alignment options in the properties menu:

1. **Open the Properties Menu for the Text**:
   - Right-click on the text element within the Banner widget, or
   - Single-click the text element and then click the ellipsis button (three dots) that appears.
2. **Adjust Text Alignment**:
   - Set the alignment to:
     - Left
     - Center
     - Right

### Creating a Slideshow

Banner widgets can be used in batches to create a slideshow. Simply add multiple Banner widgets to the same template section, and they will automatically transform into a slideshow.

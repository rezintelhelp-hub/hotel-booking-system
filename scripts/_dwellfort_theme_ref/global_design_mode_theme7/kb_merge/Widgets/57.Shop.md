# Shop Widget

The Shop widget, found in the Advanced & Setup section of the insert palette, is used to create an automatic category-based shop system where each page gets its own templated display. This allows for easy management of products without needing to edit individual pages.

## Adding the Shop Widget

1. **Open the insert palette**
   - Click the plus icon (+) to open the insert palette.
2. **Select the Shop widget**
   - Drag the Shop widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Shop"></span> from the Advanced & Setup section into the editor.
3. **Open the properties menu**
   - Right-click the Shop widget or click on it and then click the ellipsis (three dots) button to open the properties menu.

## Configuring the Shop Widget

1. **Tag**
   - Enter the primary tag for the shop. You can use the 'Quick-add tags' option to create the primary tag on the fly.
2. **Categories**
   - Select the tags to use as categories for the shop. Use 'Quick-add tag' to create and select tags on the fly.
3. **Related products tags**
   - Enter tags for related products.
4. **Read more text**
   - Customize the "Read more" text.
5. **Show products as category preview**
   - Toggle to show products as the category preview.
6. **Show categories heading**
   - Toggle to show the categories heading.
7. **Sidebar categories text**
   - Enter the name for the 'categories' sidebar that displays to the visitor.
8. **Show search**
   - Toggle to show the search option.
9. **Show image**
   - Toggle to show images on the shop index.
10. **Search result text**
    - Customize the search result text.
11. **Grid mode**
    - Toggle to enable grid mode for product display.
12. **Show share links**
    - Toggle to show share links.
13. **Hide future dated products**
    - Toggle to hide products with future dates.
14. **Enable reviews**
    - Toggle to enable reviews for products.
15. **Reviews require approval**
    - Toggle to require approval for reviews before they are displayed.
16. **Main index image width**
    - Set the width for images on the main index.
17. **Main index image height**
    - Set the height for images on the main index.
18. **Main index image width (grid)**
    - Set the width for images on the main index when in grid mode.
19. **Main index image height (grid)**
    - Set the height for images on the main index when in grid mode.
20. **Force index page**
    - Toggle to force the index page setting.

## Adding Products to the Shop

1. **Filter Pages & Content view by your tag**
   - Navigate to Pages & Content and filter the view by the primary tag you set for the shop.
2. **Add new product pages**
   - Click the plus icon (+) to open the insert palette. You’ll see the 'Product page' template automatically available. Drag this to the list of pages to add it to the shop system.
3. **Categorize new products**
   - Use the 'Categories' menu in the properties menu of each product page to categorize it by choosing from the 'Categories' menu, which will automatically include the tags you selected in the 'Categories' menu in the shop configuration.

## Configuring Product Pages

When pages are created with the 'Product page' template, they have options specific to the shop system in addition to normal page options. These options can be seen in the properties menu for a product page in the Pages & Content list:

1. **Description**
   - Add a description for the product.
2. **Created date**
   - Displays the date the product was created.
3. **Gallery**
   - Select a storage tag to represent the collection of images for the product.
4. **Files**
   - Select a storage tag to represent the collection of files for the product.
5. **Stock**
   - Enter the number of items in stock.
6. **Code**
   - Enter a unique code for the product.
7. **Variant**
   - Enter the variant of the product (e.g., color or size).
8. **Unavailable**
   - Toggle if the product is unavailable.
9. **Unavailable Message**
   - Enter a message to display when the product is unavailable.
10. **Price**
    - Enter the price of the product.
11. **Options**
    - Enter a comma-separated list of options and prices here. If this is populated, the normal Price value is ignored. Format like this: `Small:9.99,Medium:15.99,Large:19.99`.
12. **Only One In Basket**
    - Toggle to limit the product to one per basket.
13. **Original Price**
    - Enter the original price of the product if it is on sale.
14. **Permission Roles**
    - Select the permission roles that can access this product.

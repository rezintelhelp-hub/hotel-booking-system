# Using the Searchable Preview Based Subpage Index Widget

The Searchable Preview Based Subpage Index widget is a powerful tool that allows you to display an interactive index based on the subpages that belong to the page you add the widget to.

## Adding a Searchable Preview Based Subpage Index Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the **Searchable Preview Based Subpage Index** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Searchable_Preview_Based_Subpage_Index"></span> to the desired location on the page.

### Example Usage

For example, if you have a main menu page called 'Products' with several subpages, you can:
1. Edit the 'Products' page.
2. Add the **Searchable Preview Based Subpage Index** widget to it.

**Important**: This widget is designed to work on a parent page that has a single list of subpages. Consider using the 'Searchable Subpage Index' widget if you want to display a sub-categorized list of pages.

## Configuring Subpages

1. **Edit Each Subpage**:
   - Edit each of the product subpages in turn and populate the **Page Preview**. These snippets will show on the index page but won't actually display on the subpage itself. Keep them concise, perhaps just a title and an introductory paragraph.
2. **Example Configuration**:
   - When the widget is configured on the parent page, it will display an index of the subpages. For instance, if the parent page has three subpages, the widget will show previews for each of these subpages.

## Adding Keywords for Search

1. **Access the Properties Menu**:
   - Navigate to **Pages & Content**.
   - Locate the subpage you want to edit.
   - Right-click on the subpage, or single-click the subpage and then click the ellipsis button (three dots) that appears to open the properties menu.
2. **Edit Meta Keywords**:
   - In the properties menu, find and select the **Meta Keywords** option.
   - Enter a list of keywords separated by commas.
3. **Search Mechanism**:
   - The keywords added to each subpage will power the search feature. When a visitor uses the search box on the page with the widget, it will match their search terms against these keywords and update the list to show only the matching pages.

By following these steps, you can effectively use the Searchable Preview Based Subpage Index widget to create an interactive and searchable index for the subpages on your website.

# Using the Floating Sub Menu widget

The Floating Sub Menu widget is a powerful tool that lets you create advanced interactive pages by defining different sections and linking them through a floating menu.

## Defining Your Sections

To use the Floating Sub Menu, you need to define the different sections on your page with a small piece of code. This is done using Embed Codes.

### Steps to Define Sections

1. **Add a New Embed Code Widget**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the Embed Code widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Embed_Code"></span> to the desired location on the page.
2. **Naming the Widget**:
   - When you first add the Embed Code widget to the page, you will be prompted to give it a name for your reference. This name is for organizational purposes and is not where you add the actual code.
3. **Enter the Embed Code**:
   - Once the instance of the Embed Code widget is on the page, open the properties menu:
     - Right-click on the Embed Code widget, or
     - Single-click the widget and then click the ellipsis button (three dots) that appears.
   - In the properties menu, locate the **Embed Code** field.
   - Enter code like this in the **Embed Code** field: `<div id="section1"></div>`. Notice we have added 'section1' - this is a unique text string that we'll use later. It mustn't contain any spaces or odd characters.
   - Save the changes.

Repeat these steps for each section you want to define on your page.

## Adding the Floating Sub Menu Widget

Once you've defined each section on your page using the above method, you can add the Floating Sub Menu widget itself.

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the Floating Sub Menu widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Floating_Sub_Menu"></span> to the very top of the editor.

The Floating Sub Menu widget is large and contains many editable zones. It can accommodate links to up to 10 separate sections. For each link, there are three separate zones:

1. **Link1**
2. **Link1 Text**
3. **Link1 Icon**

## Populating the Widget

### Example Configuration

For example, for the first link:
- **Link1**: Add the unique section string from the 'Defining Your Sections' step (e.g., `#section1`). **Make sure the value starts with a `#`**.
- **Link1 Text**: Add some text for the visible link.
- **Link1 Icon**: Add an image for an icon.

By populating these zones, you create a navigable sub menu that interacts with your defined sections.

## Functionality

As you scroll the page, the Floating Sub Menu will pin itself to the top of the window, providing easy access to the different sections defined on your page.

By following these steps, you can effectively use the Floating Sub Menu widget to create interactive and user-friendly navigation on your website.

# Using the Conditional Form Toggle Widget

The Conditional Form Toggle widget allows you to set up conditional rules for displaying form fields based on the values entered or selected in other form fields. This widget requires the Advanced Form widget to be used.

You use one instance of this widget for each form field or collection of form fields that you want to have conditional visibility. Use Groups to insert Form Conditional Widgets within the editable zone of your Advanced Form, and then place the form fields inside the editable zone of this widget.

To configure the widget, right-click on it or click on the widget and then click the ellipsis button (...) to open the properties menu.

## Properties Menu Options

1. **Rules**
   - Enter a JSON-formatted string of rules.
   - Example JSON Code:
     ```json
     [
       {
         "ID": "fieldID1",
         "operator": "==",
         "Value": "value1"
       },
       {
         "ID": "fieldID2",
         "operator": "!=",
         "Value": "value2"
       }
     ]
     ```
     In this example, the rules array contains the conditions for displaying the form fields. Each rule object includes:
     - **ID**: The ID of the form field.
     - **operator**: The comparison operator (e.g., `!=`, `==`, `>`, `<`).
     - **Value**: The value to compare against.

2. **Visible when all rules are met**
   - Determines whether the content should be visible when any or all of the rules are met.
   - Options: `Any` or `All`
   - This setting controls the logic matching:
     - **Any**: The logic will match if any of the rules are true.
     - **All**: The logic will match only if all of the rules are true.

## Tips for Using the Conditional Form Toggle Widget

- **Familiarize yourself with JSON**: Ensure you have a basic understanding of JSON to configure the conditional rules effectively.
- **Use Field IDs**: Reference the field IDs accurately to ensure the correct conditions are applied.
- **Test Your Form**: After setting up the conditional rules, thoroughly test your form to confirm that the conditional visibility works as expected.

By using the Conditional Form Toggle widget, you can create dynamic and responsive forms that enhance the user experience by displaying relevant fields based on user input.

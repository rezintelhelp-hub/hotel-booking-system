# Using the Search Widget

The Search widget allows users to enter a text string to search your entire website.

## Adding a Search Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the **Search** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Search"></span> to the desired location on the page.

## Placement Recommendations

- **Page Placement**: Add the Search widget to any page to include the search form at that location.
- **Sitewide Content Area**: Consider adding the Search widget to a sitewide content area, such as a column in the footer, as this is a naturally good place for it.

By following these steps, you can effectively utilize the Search widget to improve your website's functionality, making it easier for users to locate the information they seek.

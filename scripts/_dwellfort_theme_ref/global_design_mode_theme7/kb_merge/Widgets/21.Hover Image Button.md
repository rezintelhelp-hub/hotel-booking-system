# Using the Hover Image Button Widget

The Hover Image Button widget allows you to create a button out of an image that automatically fades to another image when the user hovers over it. This can create a visually appealing interactive effect for your website.

## Preparing Your Images

1. **Prepare Two Images**:
   - Ensure both images are the same size.
   - One image represents the normal state, and the other represents the hover state.
   - It works best if you use an image that stays the same except for a different color or slight variation for the hover version.

## Adding a Hover Image Button Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the Hover Image Button widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Hover_Image_Button"></span> to the desired location on the page.

## Configuring the Hover Image Button Widget

1. **Main Image and Link**:
   - The first editable zone in the widget is called **Main image and link**.
   - This zone allows you to decide where the image button will link to when clicked.
   - To add an image, drag it into the **Main image and link** zone, either from the Insert Palette or from elsewhere on the page.
   - To add a link to the image:
     - Open the properties menu for the image.
     - Click the **Link** option.
     - Enter the link address.
2. **Hover Image**:
   - The second editable zone is for the **Hover image**.
   - Drag your hover state image into this zone, either from the Insert Palette or from elsewhere on the page.

By following these steps, you can effectively use the Hover Image Button widget to create an interactive button that enhances user engagement on your website.

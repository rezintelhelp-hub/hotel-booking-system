# Using the Carousel Slide widgets

The Carousel Slide widget is designed to be used in normal content areas and allows you to create an interactive carousel slideshow. This widget contains an editable zone for any type of content.

## Adding a Carousel Slide Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Drag the Carousel Slide widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Carousel_Slide_SS9"></span> to the desired location on the page.
2. **Adding Content**:
   - Once the Carousel Slide widget is added to the page, locate the **Content** editable zone within the widget.
   - To add content, drag items into the **Content** editable zone, either directly from the Insert Palette or from elsewhere in the editor.

## Creating a Slideshow

To create a carousel slideshow, add multiple Carousel Slide widgets consecutively. This will automatically create an interactive slideshow of your content.

## Configuring the Slideshow

There are four options in the properties menu that can be set to configure the slideshow. You only need to set these options on the first instance of the widget in any collection of Carousel Slide widgets.

1. **Autoscroll Speed**:
   - Sets the speed in seconds for the slides to advance.
   - Set to 0 to disable autoscroll.
2. **Number of Items**:
   - Specifies the number of items to fit on one page.
3. **Show Side Buttons**:
   - Toggles the visibility of left/right arrow buttons to allow users to skip between slides.
4. **Show Pagination Dots**:
   - Toggles the visibility of dots representing each slide below the slideshow.

By following these steps and configuring the options, you can effectively use the Carousel Slide widget to create an engaging and interactive slideshow on your website.

# Page Comments Widget

The Page Comments widget allows users to add a thread of comments to any page. It is located in the Advanced & Setup section of the Insert Palette.

## Adding the Page Comments Widget to a Page

1. **Insert Palette**
   - Click the plus icon (+) to open the Insert Palette.
   - Navigate to the Advanced & Setup section.
   - Drag the Page Comments widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Page_Comments"></span> to the desired location on your page.

## Configuring the Page Comments Widget

To configure the Page Comments widget, follow these steps to open the properties menu:

1. **Open Properties Menu**
   - Right-click on the widget or click on it and then click the ellipsis (three dots) button.
2. **Enable Require Approval**
   - If you enable 'require approval,' then comments won't show on the website until you tick the Approved box for the comment in your Activity feed.

## Adding Comments

Visitors to the website can add comments as follows:

1. **Logged-in Users**
   - If users are logged in, their comments are automatically posted by them.
2. **Non-logged-in Users**
   - Non-logged-in users will need to enter their email address to post a comment.

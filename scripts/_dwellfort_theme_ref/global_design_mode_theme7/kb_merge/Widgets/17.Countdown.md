# Using the Countdown widget

The Countdown widget displays an animated countdown until a specified future date and time. This guide will explain how to add the Countdown widget to your page, set the target date, and add content to be shown once the countdown is complete.

## Adding a Countdown Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Advanced & Setup** section.
   - Drag the Countdown widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=CountdownSS9"></span> to the desired location on the page.

## Setting the Target Date and Time

To make the Countdown widget work, you need to set the target date and time in the properties menu.

1. **Open the Properties Menu**:
   - Right-click on the Countdown widget, or
   - Single-click the widget and then click the ellipsis button (three dots) that appears.
2. **Edit the Date Option**:
   - In the properties menu, locate the **Date** option.
   - Enter the target date and time in the following format:
     ```
     YYYY/MM/DD HH:MM:SS
     ```
   - For example, to set the countdown to 28th June 2017 at 8 PM, enter:
     ```
     2017/06/28 20:00:00
     ```

## Adding Content to Show When Complete

The Countdown widget includes an editable zone called **Show when complete**. This zone allows you to add content that will be displayed once the countdown reaches the target date and time.

1. **Locate the 'Show when complete' Editable Zone**:
   - Once the Countdown widget is added to the page, find the **Show when complete** editable zone within the widget.
2. **Adding Content**:
   - To add content, drag items into the **Show when complete** editable zone, either directly from the Insert Palette or from elsewhere in the editor. Refer to [working with text](#working-with-text) for detailed instructions on how to add and format text items.

By following these steps, you can effectively use the Countdown widget to display an animated countdown and show specific content once the countdown is complete, enhancing the interactivity and engagement of your website.

# Using the Callout Widget

The Callout widget is a quick way to highlight some content on a page. This widget allows you to draw attention to specific information or announcements effectively.

## Adding a Callout Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Drag the Callout widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Callout"></span> to the desired location on the page.
2. **Adding Content**:
   - Once the Callout widget is added to the page, locate the **Content** editable zone within the widget.
   - To add content, drag items into the **Content** editable zone, either directly from the Insert Palette or from elsewhere in the editor.

By following these steps, you can efficiently use the Callout widget to emphasize important information and make your content stand out.

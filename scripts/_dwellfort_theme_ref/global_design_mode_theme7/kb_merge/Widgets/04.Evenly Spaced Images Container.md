# Using the Evenly Spaced Images Container Widget

The Evenly Spaced Images Container widget allows you to display images evenly spaced out across the page. This is a simple and effective way to showcase multiple images in a clean and organized layout.

## Adding the Evenly Spaced Images Container Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Media & Files** section.
   - Drag the **Evenly Spaced Images Container** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Evenly_Spaced_Images_Container"></span> to the desired location on the page.

## Adding Images

1. **Add Images**:
   - The widget has an editable zone called **Images**.
   - Drag and drop images into this **Images** editable zone. The widget will automatically space them evenly across the page.

## Configuring Image Size

1. **Open the Properties Menu**:
   - Right-click on the widget, or
   - Single-click the widget and then click the ellipsis button (three dots) that appears.
2. **Set Image Size**:
   - Use the **Size** option in the properties menu to choose between **Small**, **Medium**, or **Large** for the images.

By following these steps, you can effectively use the Evenly Spaced Images Container widget to display images in a visually appealing and evenly spaced layout on your website.

# Using the Sub Pages List with Filter Widget

The Sub Pages List with Filter widget is a powerful tool that allows you to build an index of pages with a filter tool to let visitors refine the list of pages based on specified criteria.

## Setting Up the Structure

1. **Create a Parent Page**:
   - Create a top-level page which will serve as the 'parent' page.
   - Add subpages to this parent page. These subpages will be the list of pages that will be filterable.

## Adding Meta Data for Filtering

1. **Edit Each Subpage**:
   - Navigate to **Pages & Content** and locate a subpage you want to edit.
   - Open the properties menu for the subpage:
     - Right-click on the subpage, or
     - Single-click the subpage and then click the ellipsis button (three dots) that appears.
   - Click **Meta Keywords**.
2. **Enter Meta Keywords**:
   - Enter the keywords in the following format:
     ```
     Category: Value, Category: Value
     ```
   - For example:
     - Subpage 1: `Color: Red, Size: Small`
     - Subpage 2: `Color: Blue, Size: Medium`

## Adding the Sub Pages List with Filter Widget

1. **Edit the Parent Page**:
   - Open the parent page you created.
2. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the **Sub Pages List with Filter** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Sub_Pages_List"></span> to the desired location on the parent page.

## Example Configuration

For example, if you have a parent page called "Products" with subpages for categories like "Cupboard Items," "Breads," and "Vegetables," and each of these subpages has meta keywords such as `Color: Red, Size: Small`, the widget will generate filters for 'Color' and 'Size' based on the values you have entered. This allows visitors to refine the list of subpages based on these criteria.

By following these steps, you can effectively use the Sub Pages List with Filter widget to create an interactive and searchable index of subpages on your website, enhancing navigation and user experience.

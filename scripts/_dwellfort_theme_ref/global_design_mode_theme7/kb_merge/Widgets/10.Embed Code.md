# Using the Embed Code Widget

The Embed Code widget allows you to insert HTML code directly onto a page. This widget is useful for embedding third-party systems or creating advanced functionality that requires direct control over the HTML output.

## Adding an Embed Code Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the Embed Code widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Embed_Code"></span> to the desired location on the page.
2. **Naming the Widget**:
   - When you first add the Embed Code widget to the page, you are prompted to give it a name for your reference. This name is for organizational purposes and is not where you add the actual code.

## Adding the HTML Code

1. **Open the Properties Menu**:
   - Once the instance of the Embed Code widget is on the page, right-click on the widget, or
   - Single-click the widget and then click the ellipsis button (three dots) that appears.
2. **Enter the Code**:
   - In the properties menu, locate the **Embed Code** field.
   - Enter your HTML code into the **Embed Code** field.

By following these steps, you can effectively use the Embed Code widget to add custom HTML content to your page, enabling advanced functionality and integrations with third-party systems.

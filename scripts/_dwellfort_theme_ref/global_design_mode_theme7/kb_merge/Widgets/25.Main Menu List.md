# Using the Main Menu List Widget

The Main Menu List widget displays your main menu pages in a list wherever it's added. This is useful if you want to include your main menu pages in a sitewide content area, such as the footer.

## Adding a Main Menu List Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the **Main Menu List** widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Main_Menu_List"></span> to the desired location on the page.

By following these steps, you can effectively use the Main Menu List widget to display your main menu pages in a list, enhancing the navigation and accessibility of your website.

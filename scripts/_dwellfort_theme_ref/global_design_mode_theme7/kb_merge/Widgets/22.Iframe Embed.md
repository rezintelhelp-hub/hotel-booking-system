# Using the Iframe Embed Widget

The Iframe Embed widget makes it easy to embed a standard iframe embed code in a way that ensures it stays fully responsive.

## Adding an Iframe Embed Widget

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Page Feature** section.
   - Drag the Iframe Embed widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Iframe_Embed"></span> to the desired location on the page.

## Adding and Configuring the Embed Code

1. **Open the Insert Palette**:
   - Click the **+** button to open the Insert Palette.
   - Navigate to the **Embed Codes** section.
   - Drag the Embed Code widget <span class="icon-widget"><img src="/admin/graphics/adminthemeassets.php?show=widgets&name=Embed_Code"></span> to the desired location on the page.

2. **Naming the Embed Code**:
   - When you first add the Embed Code widget to the page, you will be prompted to give it a name for your reference. This name is for organizational purposes and is not where you add the actual code.

3. **Enter the Embed Code**:
   - Once the instance of the Embed Code widget is on the page, open the properties menu:
     - Right-click on the Embed Code widget, or
     - Single-click the widget and then click the ellipsis button (three dots) that appears.
   - In the properties menu, locate the **Embed Code** field.
   - Ensure your iframe embed code does not contain fixed width and height values.
   - For example, if your original code is:
     ```html
     <iframe width="580" height="360" src="https://www.youtube.com/embed/gtIz1u8g1F0" frameborder="0" allowfullscreen></iframe>
     ```
   - Change it to:
     ```html
     <iframe src="https://www.youtube.com/embed/gtIz1u8g1F0" frameborder="0" allowfullscreen></iframe>
     ```
   - Enter the modified iframe code into the **Embed Code** field.
   - Save the changes.

## Embedding the Iframe Code

1. **Drag the Embed Code**:
   - Drag the embed code into the **Iframe Embed Code** editable zone within the Iframe Embed widget.

By following these steps, you can effectively use the Iframe Embed widget to embed responsive iframe content on your website.

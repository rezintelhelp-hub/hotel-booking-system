# Multi Choice Question Widget

This widget is used to build online tests/training courses. An online course consists of a series of questions, each on its own page, and then a final results page that contains the Training Module Results widget.

Each question page should use this widget to build the question. You can create alternative versions of the question to give the user the opportunity to try a given question more than once. To do this, add another instance of this widget to the page and make sure it uses the same tag as the other question on the page in the 'Retest pool' tag option.

To associate a question with a test, use the same tag in the 'Belongs to test group' tag choice for each question. You can choose one or two correct answers for the question. If you use two answers, both will be required.

This widget has three editable zones:
- **Pass Content**
- **Fail Content**
- **Question**

## Configuring the Multi Choice Question Widget

To configure the Multi Choice Question Widget, you need to open the properties menu. To open the properties menu, either right-click on the widget or click on the widget and then click the ellipses button.

1. **Belongs to test group**
   - Enter the tag that associates this question with a test group.
2. **Retest pool**
   - Enter the tag that groups this question with its alternative versions.
3. **Show stats**
   - Toggle to show statistics for the question.
4. **Correct Answer 1**
   - Enter the first correct answer for the question.
5. **Correct Answer 2**
   - Enter the second correct answer for the question if needed.
6. **Distractor 1**
   - Enter a distractor answer to the question.
7. **Distractor 2**
   - Enter a second distractor answer to the question.
8. **Distractor 3**
   - Enter a third distractor answer to the question.
9. **Distractor 4**
   - Enter a fourth distractor answer to the question.

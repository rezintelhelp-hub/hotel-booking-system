# Working with Advanced Text and Image Styles

When you select text or an image on your page, you'll see the properties menu shows **Advanced Text Styles** and **Advanced Image Styles** respectively. These advanced styles allow you to customize the appearance and functionality of your text and images, enhancing your website's visual appeal and usability.

## Advanced Text Styles

- **Lead Paragraph**: Adds emphasis to a normal paragraph and is ideal for highlighting the first paragraph on a page.
- **Button Small**: Converts a text link into a small graphical button. Best used when the paragraph contains only the link, typically 2-3 words.
- **Button Medium**: Converts a text link into a medium-sized graphical button. Similar use as Button Small but with a medium size.
- **Button Large**: Converts a text link into a large graphical button. Similar use as Button Small but with a large size.
- **Smaller**: Reduces the size of the text element it is applied to. Useful for making subheadings or other text elements slightly smaller.
- **Popup Link**: Creates rich media popup links for videos, YouTube pages, or images. Add a normal link, then apply this style to the containing paragraph. For YouTube videos, link to the normal page address.
- **Icon Styles**: Adds an icon at the start of the text: Icon Tick, Icon Blocked, Icon Info, Icon Question, Icon Alert, Icon Phone, Icon Email, Icon Home.

## Advanced Image Styles

- **Caption**: Makes the image's ALT text visible along the bottom edge of the image.
- **Light Border**: Adds a light border to your image.
- **Light Border Caption**: Adds a light border to your image and displays the visible caption.
- **Heavy Border**: Adds a heavier border to your image.
- **Heavy Border Caption**: Adds a heavier border to your image and displays the visible caption.
- **Popup Link**: Creates rich media popup links for videos, YouTube pages, or images. Add a normal link to the image, then apply this style. For YouTube videos, link to the normal page address. Works similarly to the Popup Link in Advanced Text Styles, but applied to images.

By using these advanced styles, you can effectively enhance the presentation and functionality of text and images on your website, providing a more engaging experience for your visitors.

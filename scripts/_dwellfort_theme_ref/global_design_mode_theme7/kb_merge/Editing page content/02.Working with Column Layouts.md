# Working with Columns

Column layouts in SetSeed provide a flexible and responsive way to structure your web page content. They can be easily inserted and manipulated within the editor, adapting automatically to different screen sizes on the website. The editor view is in a single list mode to allow ease of editing, while the live preview shows the webpage version and how the columns display on different device sizes.

## Inserting Column Layouts

1. **Open the Insert Palette**:
   - Click the plus icon (+) to open the insert palette.
   - Select "Column Layouts" from the left menu.
   - Drag your chosen column layout into the editor.

## Editing Column Layouts

Once a column layout is added to the editing area, it will display a thin line down the left edge. This line indicates the area where you can drag and drop other elements to place content within the labeled zones of the column layout.

## Understanding Column Zones

Each column layout consists of specific zones labeled according to their order or content significance, such as "first column" and "second column" in a simple two-column layout. The emphasis is on the order or significance rather than the exact position because:

- On some devices, columns will automatically stack on top of each other.
- It's important to consider the fluid nature of responsive design rather than fixed positions.

## Responsive Design

Column layouts are advanced responsive containers that adapt to various screen sizes. This ensures that your content remains structured and visually appealing across all devices.

### Example

A two-column layout will stack the columns vertically on smaller screens, maintaining the content order specified in the editor.

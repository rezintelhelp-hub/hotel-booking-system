# Coupon Codes Settings

The **Coupon Codes** settings in SetSeed allow you to configure discount codes that customers can enter during checkout to receive discounts on their orders. The Coupon Codes area supports up to 10 different discounts, each with its own set of configuration options.

## Accessing Coupon Codes Settings

1. Click the blue home icon in the main menu.
2. Select **Settings** from the menu.
3. Navigate to the **Coupon Codes** section in the sidebar.

## Configuring Coupon Codes

Each type of discount supports one or more codes that can be distributed to customers. The configuration tools for each discount allow you to specify how the discount code functions, including the type of discount, the amount, and any restrictions or expiry dates.

The settings for each of the 5 potential discounts are as follows:

1. **Discount # Codes**:
   - Enter one or more discount codes that customers can use. Each code should be unique to avoid conflicts.
2. **Discount # Percentage**:
   - Specify a percentage discount that will be applied to the order total when the code is used. For example, enter "10" for a 10% discount. Leave this field empty if using a fixed amount discount.
3. **Discount # Fixed Amount**:
   - Specify a fixed amount that will be deducted from the order total when the code is used. For example, enter "5" for a $5 discount. Leave this field empty if using a percentage discount.
4. **Expire on Date**:
   - Set an expiry date for the discount code. After this date, the code will no longer be valid.

By configuring these settings, you can create and manage discount codes that provide incentives for your customers, helping to increase sales and customer satisfaction.

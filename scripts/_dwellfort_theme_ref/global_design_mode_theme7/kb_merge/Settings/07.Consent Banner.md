# Setting Up the GDPR Cookie Consent Banner

The GDPR Cookie Consent Banner enables compliance with GDPR regulations by allowing users to consent to the use of cookies on your website. Follow the steps below to set up and customize the consent banner.

## Steps to Enable the Consent Banner

1. **Navigate to Consent Banner Setup**:
   - Click the blue home icon.
   - Go to **Settings**.
   - Select **Consent Banner Setup**.
2. **Enable the Consent Banner**:
   - Tick the **Enable Consent Banner** checkbox.
3. **Customize Consent Mode Information**:
   - In the **Consent Mode Info** area, enter text explaining the use of cookies on your website.
   - Include a link to your cookie policy using the CMS shortcode format:
     ```
     (Click here)["URL_of_your_cookie_policy"]
     ```
     Replace `URL_of_your_cookie_policy` with the actual URL of your cookie policy.

## Customizing Cookie Categories

The consent banner includes three cookie categories, each with editable names and explanations:

1. **Performance Category**:
   - Edit the name and explanation text to describe performance-related cookies.
2. **Functional Category**:
   - Edit the name and explanation text to describe functional cookies.
3. **Advertising Category**:
   - Edit the name and explanation text to describe advertising cookies.

Each category should clearly explain the purpose of the cookies within that category to ensure users understand their function and necessity.

## List of Cookies to Include in Your Cookie Policy

When setting up the cookie consent banner, you should add a cookie policy to your website listing cookies that are used by the website. Here are the cookies you should include:

## Core Functionality Cookies

- `assetscached` and `ac_###`
  - Used for optimizing the way assets are served to the web browser.
- `PHPSESSID`
  - Used for core functionality of the website.

## Widget Specific Cookies

Include these only if you use the corresponding widgets on your site:

1. **Video Player Widget**
   - `volume`
     - Stores preferences for media player volume.
2. **Checkout Widget**
   - `transid` and `transidvalue`
     - Used for tracking a checkout transaction.
   - `preselect_cur`, `output_cursymv3` and `output_cursym_idv3`
     - Used for preselecting and storing currency choice.
3. **Smiley Widget**
   - `smileyDone#`
     - Used for tracking smily feedback form status.
4. **Checkbox Widget**
   - `checkbox#`
     - Used for storing checkbox widget status.
5. **Popup Widget**
   - `seenPopupMessage###`
     - Used for storing popup widget status.
6. **Login Widget**
   - `user_list_token`
     - Used for allowing login functionality.
   - `googlesso`, `googlessoaddto`, `mssso`, `msssoaddto`, `fbsso` and `fbssoaddto`
     - Used for single sign-on functionality. These are only used if single sign-on is enabled.

## Summary

By following these steps, you can ensure that your website complies with GDPR regulations while providing clear information to users about the use of cookies. This setup not only helps in managing user consent but also in maintaining transparency about the data collection practices on your website. Make sure to link to your cookie policy page from the **Consent Mode Info** text for easy access by your users.

Beds24 diagnostics

Master-admin tools for the 2026-09-07 V1 key rotation. Requires a valid GAS admin session.

1. Env-var fingerprints

First 4 + last 4 + length of each Beds24-related env var on Railway. Never returns raw secrets.

Click Refresh to load.

2. Find connections by V1 key suffix

Scans every gas_sync_connections row (beds24 + beds24-marketplace) whose stored V1 API key ends with the given suffix. Use before deleting a Beds24 key to know who still relies on it.

Enter a suffix and click Search.

3. Lookup connections by Beds24 owner IDs

Given a comma-separated list of Beds24 owner IDs, show each GAS connection that matches. Defaults to the 7 owners flagged for rotation.

Click Lookup to load.
